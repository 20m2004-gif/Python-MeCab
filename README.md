# 日本語テキスト解析（Python, MeCab）

## 概要
日本語の文書を対象に、形態素解析を用いたテキストマイニングを行いました。  
夏目漱石『吾輩は猫である』のテキストをサンプルデータとして使用し、名詞の抽出や単語頻度の分析を通じて、文章の特徴を可視化しました。

## 使用技術
- Python  
- MeCab（日本語形態素解析ライブラリ）  
- Jupyter Notebook  
- matplotlib, collections.Counter  

## 実装内容
1. MeCabを用いて日本語テキストから名詞を抽出  
2. 出現頻度をカウントして上位単語を出力  
3. matplotlibを用いて頻出名詞の棒グラフを可視化  

## 主な結果
- 頻出する単語を抽出することで、文章全体の特徴語を把握  
- 単語の出現パターンからテキストのテーマ性や登場要素の傾向を分析可能  
- 日本語テキストをPythonで処理する際の基礎フローを構築
